# QORĞAU — Еңбек қауіпсіздігі

Интерактивный учебный сайт на казахском языке на тему «Еңбекті қорғау және техника қауіпсіздігі».

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей и сборка не нужны: HTML, CSS, JavaScript и SVG находятся в одном файле. Для размещения загрузите `index.html` на любой статический хостинг.

## Возможности

- Конструктор пяти средств индивидуальной защиты с индикатором полноты учебного комплекта.
- Три сценария: пожар, поражение электрическим током и химический ожог.
- Тест из пяти вопросов с объяснениями и порогом прохождения 80%.
- Именной учебный сертификат с текущей датой, скачиванием SVG и печатью в PDF.
- Адаптивный интерфейс, управление с клавиатуры и поддержка уменьшенной анимации.

Технологии: семантический HTML5, CSS3, JavaScript ES6+, встроенный SVG. Внешних библиотек и сетевых зависимостей нет.

Материалы и сертификат предназначены для обучения; сертификат не является документом о профессиональной квалификации. Дереккөздер / источники приведены внизу страницы.
